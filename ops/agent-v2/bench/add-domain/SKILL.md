# SKILL — ipradar 加源轮演化(提案者工作技能)

你在演化 ip-radar 的**加源轮**:一条在剥答案沙箱里把考题卡重实现成源接入的编码管线
(VERIFY → IMPLEMENT → GATE → REPORT)。基准世界用真逐源测试的分级钥匙给你打分。

## 基准世界(你被度量的地方)

- **考题**:33 个源接入题(冻结宇宙 universe.jsonl,从 roster 机械派生)。劈分冻结:
  25 演化集(矿掘反馈用)+ 8 留出集(终局验收用,你永远不会看到它的反馈)。
- **一次 trial**:run-trial 单题全链——剥答案沙箱(剥源/剥钥匙/剥映射,git 单根提交
  无历史)→ 沙箱内跑 bench 形态加源轮(DOSSIER 跳过,考题卡预填交接单;VERIFY 照常)
  → 轮产出 diff 泄漏闸 → 真钥匙装回沙箱原位打分。
- **打分**:score.mjs 把 repo 侧真逐源测试装回沙箱跑,**score_frac = 通过测试函数数/
  总测试函数数(#343 分级钥匙)是主判据**,轮间比逐题均分 mean_frac;score_pass 二值
  留档并存——0/1 旧制数字与均分不可直比;k≥3 的噪声带内差异不是增益。
- **faux 冒烟**:add-trial 全链(tests/add-trial.test.mjs,罐装模型面)零网络零花费,
  是每个候选编辑的必过面。
- **盲测纪律**:答案(真源实现+真测试)只在打分时装回;你手里的证据 = 矿掘报告、
  sweep 工件、护栏结果。**考题名与下载域名禁入提示词/代码/注释**——那是泄漏,
  leak gate 机检,泄漏候选一律作废。**矿掘反馈的可用面只到两层:失败层位与失败
  测试函数名**;sweep 工件里的断言原文/测试体(score.summary 的错误正文、traceback
  里的答案类名与方法面)禁读禁引——那是答案本体碎片,引了即泄漏。需要矿掘,用
  mine-failures.mjs 的输出面,不直接翻 trial.json。**主检出 backend/ipdb/**
  同为禁读面**(classification 表/既有源实现是答案侧)——你的合法读面只有 worktree
  沙箱内在场件 + 矿掘报告;主检出的 dev/ 工件(除矿掘报告)不碰。

## 你能改什么(开放面)

加源域三件:`ops/agent/prompts/add/*`(轮提示词 system/implement/dossier)、
`ops/agent-v2/tools/add-tools.mjs`(编码工具闭集)、`ops/agent-v2/tasks/add-round.mjs`
非门段(IMPLEMENT/DOSSIER 装载序列)。**门段点名禁改**:ADD_GATES/GATE_OF 定义
(tasks/add-round.mjs:607-680)、各相位 finishFailed 的 `GATE:` 红终态调用点
(:1041/:1146/:1177)、G_* 判据函数——删/改/绕门与改 tests 同罪,faux 冒烟与裁判
测试会拒。机器面:策略面白名单(#327 七条 glob,EDIT_ALLOWLIST)圈定可编文件;
`tests/**` 不在名单里——裁判面天然钉死。

## 工作循环

1. 读分析师报告:`node bench/add-domain/mine-failures.mjs <sweepDir>` 对主会话提供的
   sweep 工件(dev/ 本地件,不入仓)出矿掘——哪些题死在哪层、哪些断言函数反复红。
   已被拒绝的机制是负证据,不要原样重提。
2. 提 ≤b_t 个可归因编辑(每个编辑一个假设:「预期救回哪些题的哪层失败、为什么」),
   编辑预算随轮退火——晚轮只允许单点改动。
3. 候选过三护栏才算活:v2 全套(`npm test`)+ leak gate(`bench/leak-check.mjs`
   exit 0)+ faux 冒烟(add-trial 全链)。
4. 真扫是花钱面(真实模型逐题逐次):主会话按长期授权(m01882)逐批跑、台账照记
   (spend.json,花费帽在开沙箱前拦);提案者本人零真扫零网络。

## 心法(域内先验)

- 失败三种层位(矿掘报告已归层,先读层再选刀):
  ① **verify-gate** = 证据基问题——门找不到活性证据(直接探活响应头、代码托管家族
  release/commit 面)就 fail-closed。门是裁判面禁改,这层没有你的刀:如实上报,
  人面裁证据基扩展(#345 先例),不要试图用提示词绕门。
  ② **collection-error** = 导入/类名层——钥匙测试 import 不到模块或类名,实现根本
  没装上。刀在交接面:考题卡→实现提示词的命名与装载约定。
  ③ **behavior** = 实现深度层——装上了但逐源特异行为不过(列形、脏行容错、键形
  成员查询、证据形状约定)。刀在实现提示词与工具;编辑必须说清救的是哪一类断言,
  通用大词(「更严谨」「更完整」)不算假设。
- 快红≠死题:先怀疑机器面(#344 判例:高延迟源连接尝试超时缺省太短,抢跑判死),
  再怀疑证据基(#345 判例:门天花板压住题面),最后才轮到实现深度。
- baseline 矿掘判例:失败几乎全是逐源特异断言,跨题共性家族极少——「一族断言反复红」
  是强信号;「每题红一个不同断言」= 提示词通用面已枯竭,该换杠杆(报人面),
  不是再堆形容词。

## 红线(触线即作废,分数再高也不接受)

- **裁判面禁改**:`tests/**`(机器钉死)、`bench/add-domain/score.mjs`、gen-universe/
  宇宙/考题卡(答案与分母)、G_* 门语义(tasks/add-round.mjs 门段)、leak gate 执法件。
  发现评测器缺陷,报告,不修。
- 考题名/下载域名禁入一切编辑面;沙箱纪律:轮工件只落沙箱 run-dir,不写真实运营面
  台账;模型 key 走 env,零入仓。
- 逐题打补丁(benchmark 专属拟合)= 拒绝;编辑必须表述为可泛化机制。修评审意见
  只修意见所及,不夹带。
