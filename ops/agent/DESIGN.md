# 运营 agent 设计(DESIGN)

一句话:**给模型回路,不给模型结论**——模型的能力花在消耗可证伪的信号上,不花在复述喂给它的读数上。摘要员时代(2026-10-19 七裁的保守产物)就此退役:确定性归脚本,判断归模型步,裁决归人。

## 1. 提示词设计理念(八条律;提炼自 MP,出处=研究 §1.1)

1. **回路优先**:先证明「这条结论能被一条命令复现/证伪」,再谈根因。给模型可消耗的探针回路,不给预消化的报告。出处:diagnosing-bugs/SKILL.md:20「This is the skill. Everything else is mechanical.」
2. **可证伪假设**:每条判断写成「若 X 为因,则改 Y 会消失/显形」的预测形;说不出预测=胡猜,弃。出处:diagnosing-bugs:90-96。
3. **阶段门(done-when)**:每阶段有完成判据,由宿主机检(工件布尔行/门函数),不信模型自报。出处:diagnosing-bugs:66「No red-capable command, no Phase 2.」
4. **反模式+tell**:每种反模式给识别征候(「tell:」),让下一轮/下一个 agent 认得它。出处:tdd/SKILL.md:30-31。
5. **点名失败模式**:提示词里直接点名它要防的失败(「如果你发现自己在复述读数而没亲手复验——停,复述正是本提示词要消灭的失败模式」)。出处:diagnosing-bugs P1 末段。
6. **小入口+按需深读(信息阶梯)**:全轮必读的留文内,分支才要的挂指针文件;环境可查物不复述。分流判据出处:writing-for-agents/SKILL.md:39。
7. **亮工作过程**:每条结论挂它消费的信号(call_id/工件指针),宿主可回算;evidence 只收 `call_id+field` 选择对、宿主回填值——结构性消灭复述漂移。出处:diagnosing-bugs:59 + 比稿 A G5。
8. **非阻塞检查点**:模型产推荐(➡️),不等人在场;人裁异步在四键面。出处:grilling/SKILL.md:13-15 + diagnosing-bugs:98。

配套写作纪律(附录 A 执审):动词命令句;每条禁令配正向目标句;主张挂出处;脱敏先行(密钥/令牌形样 `<REDACTED>`,1113 事故制度化);AI 生成声明由宿主脚注渲染。

## 2. 三层词汇(2026-10-23 立词,入 GLOSSARY)

| 层 | 职责 | 内容 |
|---|---|---|
| **提示词层** | 判断 | 系统提示内容:角色/回路/阶段门/反模式 tell/few-shot 指针 |
| **装配层** | 上下文构造 | 锚判例预注入/按需检索/轮间 handoff 指针纪律(只指不复制,防双源漂移);索引是地图不是存储(派生可再生) |
| **宿主层** | 编排与防线 | 轮次派生/工具白名单/沙箱断言/transcript 工件/retro 钩子/预算卡;调用权在宿主不在模型(MP disable-model-invocation 精神) |

职责线:**宿主层只编排不判断,提示词层只判断不编排,脚本步只测量不判断。**

## 3. 责任线(判例 0db23018 的形式化)

- 「Finding facts is your job. The decisions are the user's.」(grilling/SKILL.md:28)
- 「The agent never stands in for the human's side of it.」(wayfinder/SKILL.md:75)

落到机制:运营 agent 的任何一步不持执行面;唯一写口 = 待审条目(四键人裁);可逆闭集自动执行只存在于 P1 四键面(ADR 0006),与本层无关。全部 flag-only 线 = 永久人裁通道。

## 5. 架构定案(设计它两次;2026-10-23 用户令「继续裁」批准)

三稿入仓:[A 工具面](../../notes/p2-design-a-toolfirst-2026-10-23.md) / [B 记忆面](../../notes/p2-design-b-memoryfirst-2026-10-23.md) / [C 流程面](../../notes/p2-design-c-pipelinefirst-2026-10-23.md)。

**定案 = C 骨架 + B 三件 + A 一律**:
- **C 骨架**:轮次状态机宿主(≤10 状态,定义表数据化),模型只在 TRIAGE/DEEP/SYNTH 三步;全部阶段门=纯函数机检(gates.json 留痕);任意步可 replay;信封零新错误词;P0-P5 增量迁移(位等价/影子对照/OPS_PIPELINE=legacy 一键回滚)。
- **B 三件**(并入装配层):`_INDEX.md` 召回地板(派生可再生)/锚判例域词表/判例升格通道(同因留痕≥2+三门槛+人裁)。
- **A 一律**(进 G_DEEP 写前门):evidence 只收 `call_id+field` 选择对,宿主回填值——结构性消灭复述漂移。

附带三小裁(全「是」):①空转金轨迹保活(每轮 DEEP 至少跑一条 canned-假设 faux 回路,零成本保活性);②refuted 也产低危消化条目(severity=low,四键面默认折叠,判例来源多一轴);③cron 首窗 04:00 起错峰。

实施 spec:GitHub issue 见仓;DESIGN.md 为理念层真源,C 稿为结构层详设(冲突时以本文件裁定为准)。
