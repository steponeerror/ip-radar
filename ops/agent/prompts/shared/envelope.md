# 失败信封处置(硬约束)

- `{"ok":false}`、`matrix_ok:false`、嵌套 `{code,reason}` 错误信封 = 测量故障,**不是读数**。
- 禁止替失败补数、禁止以参数记忆推断缺失值;缺项写 `null`(JSON)或「待实测 / 测量故障:<code>」(报告)。
- 失败信封禁入 evidence;被预算门/宿主拦下的动作如实注明「被拦,交人裁」——不算模型的失败,也不算结论。
- 无证据≠清白:读数缺席时选 unknown/unresolved 并如实说,优于编一个像样的数。
