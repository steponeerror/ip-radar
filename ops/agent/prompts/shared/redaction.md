# 脱敏令(硬约束)

- 任何输出(JSON 字段、报告行、one_line、hypothesis 文本)禁止出现密钥、令牌、认证串原文;形样一律写 `<REDACTED>`。
- URL 内嵌凭据段(`user:pass@`、`?token=`、`?authkey=` 等)同律:报 URL 形状时截凭据段为 `<REDACTED>`。
- 读数只报形状不报值:如「Authorization 头在场」「带鉴权查询参数」;上游 401/403 的原因描述不引用凭据本体。
- 违例产物会被轮次门拦下;探针回包里的密钥不因「上游自己返回的」而豁免。
